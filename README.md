GameStore — Java Spring Boot

GameStore — учебный проект интернет-магазина компьютерных игр, разработанный в рамках обучения по направлению «Разработка программного обеспечения».

Технологии

Java 21

Spring Boot 4.1.1

Spring Data JPA

Spring Security

Thymeleaf

Gradle

Oracle Database Free

MinIO (S3-совместимое хранилище)

Docker Compose

Реализованные возможности

Просмотр каталога компьютерных игр.

Категории игр.

Постраничный вывод каталога.

Авторизация пользователей.

Разграничение прав доступа по ролям USER, MANAGER и ADMIN.

Администрирование игр и категорий.

Управление ролями пользователей.

Загрузка и отображение изображений игр через MinIO.

Мягкое удаление игр.

Требования для запуска

Для запуска проекта необходимы:

JDK 21.

Docker Desktop с поддержкой Docker Compose.

IntelliJ IDEA или другая среда разработки Java.

PowerShell для выполнения скриптов восстановления.

AWS CLI v2 для восстановления изображений MinIO.

Подготовка окружения

Клонировать репозиторий.

Создать файл .env в корне проекта на основе .env.example.

Заполнить необходимые переменные окружения.

Файл .env содержит учётные данные и не должен публиковаться в GitHub.

Запуск контейнеров

Из корня проекта выполнить:

docker compose up -d

Проверить состояние контейнеров:

docker compose ps

Резервные копии

В проекте подготовлены резервные копии демонстрационных данных.

Oracle

Файл backups/oracle/gamestore.dmp содержит экспорт схемы GAMESTORE, включая таблицы игр, категорий и пользователей.

MinIO

Папка backups/minio/gamestore-images/ содержит 38 изображений игр с исходными именами объектов.

Восстановление данных

Перед восстановлением необходимо запустить Docker-контейнеры и дождаться готовности Oracle и MinIO.

Для восстановления Oracle подготовлен скрипт:

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\restore-oracle.ps1

Скрипт рассчитан на новую базу с пустой схемой GAMESTORE. Если таблицы уже существуют, восстановление останавливается во избежание конфликтов.

Для восстановления изображений MinIO:

powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\restore-minio.ps1

Скрипт использует AWS CLI и учётные данные MinIO из файла .env. При необходимости создаётся бакет gamestore-images.

Важно: скрипты восстановления подготовлены, но полноценное восстановление на чистом окружении пока не проверялось. При запуске на другом компьютере могут потребоваться дополнительные настройки.

Проверка резервных копий

В проекте предусмотрен отдельный PowerShell-тест:

powershell -NoProfile -ExecutionPolicy Bypass -File .\testbackup\test-backups.ps1

Он проверяет:

Наличие и ненулевой размер дампа Oracle.

Наличие 38 файлов изображений MinIO.

Синтаксис PowerShell-скриптов восстановления.

Тест успешно выполнен в среде разработки. Он не осуществляет фактический импорт данных.

Запуск приложения

После подготовки базы данных и MinIO приложение можно запустить через IntelliJ IDEA, используя класс GameStoreApplication.

Также можно использовать Gradle Wrapper:

.\gradlew.bat bootRun

Для подключения приложения должны быть правильно заданы параметры Oracle и MinIO.

Текущее состояние

Проект является учебной работой. Основной функционал интернет-магазина реализован, однако отдельные возможности могут требовать дальнейшего тестирования и доработки.

Резервные копии содержат демонстрационные данные и учебные учётные записи, не предназначенные для использования в реальных системах.
